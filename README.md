## Descrição
Sistema desenvolvido em Python para simular o atendimento de uma lanchonete.

O programa permite que o cliente escolha produtos do cardápio,
informe quantidades, faça vários pedidos e finalize a compra.

Ao final, o sistema calcula o desconto de acordo com o valor total,
solicita a forma de pagamento e apresenta um resumo da compra.

## Funcionalidades

- Identificação do cliente
- Exibição de cardápio
- Seleção de produtos
- Escolha de quantidade
- Cálculo de subtotal
- Acúmulo do valor total
- Validação de opções
- Desconto de 0%, 5% ou 10%
- Forma de pagamento
- Resumo final do pedido

## Como executar

1. Tenha o Python instalado.
2. Baixe o arquivo `lanchonete.py`.
3. Execute no terminal:

python lanchonete.py
